# 地图素材投放说明

把文件放进这个目录，然后 `node build.js`，构建时会自动内联进 index.html（data URI），
运行时优先用素材；**没有素材就自动回落到程序化地形**，不会白屏。

## 需要什么

| 文件 | 尺寸 | 要求 |
|---|---|---|
| `bg.jpg`（或 `bg.png`） | **1600×900** 或更大，16:9 | 俯视地形底图，**不要带任何文字/地名/图标**。草绿+土黄、有山有河即可 |
| `city-strong.png` | 高约 **256px** | 透明背景的城池立绘（掌握好） |
| `city-mid.png` | 同上 | 中等 |
| `city-weak.png` | 同上 | 弱（比如破败、着火、旗子倒了） |
| `city-untested.png` | 同上 | 可选。没测过的段（比如灰蒙蒙的废墟/空地） |

城池图最好是**等距俯视**、底部中心对齐（因为绘制时是把图片的底部中心锚在城池坐标上）。

## 体积预算

- 底图 1600×900 JPEG q75 ≈ 150–250 KB
- 四张城池 PNG（256px 高，透明）≈ 每张 30–80 KB

全部加进去，产物从 2.2 MB 涨到约 2.6–2.8 MB，仍然可以双击打开、断网可用。

## 没有现成素材时

直接用提示词生成：

> 俯视视角策略游戏地图，欧洲中世纪手绘风，温润的草绿与土黄地形，起伏丘陵与山脉，蜿蜒河流，几片森林，暖色柔光，无文字无标注无建筑，16:9 横版

> 等距俯视的中世纪城堡，透明背景，细腻的手绘游戏原画风，石墙与红瓦屋顶，正面朝向镜头，底部居中，256px 高

## 放好之后

```bash
node build.js        # 控制台会打印「地图素材: 已内联」
```

然后打开 `index.html` → 总览 → 打开词汇地图。
