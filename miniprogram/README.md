# 四六级词汇量检测 · 微信小程序

网页版（单文件 `index.html`）的小程序版本。**统计引擎、答题流程与网页版逐字段一致**
（三套一致性测试可复跑），只重写了视图层，并针对手机做了一版移动端界面。

数据、算法、口径全部和网页版同源：词库 7,175 词、例句 5,138 个词（9,204 句语料里每词取一句）、
分层抽样、区间估计三层修正、蒙对校正、七段剖面、等级 + 地基封顶。

## 二、页面结构（底部三个 Tab + 两个流程页）

| 页面 | 内容 |
| --- | --- |
| **首页** `pages/index` | 词汇量卡（数字 + 95% 区间 + 折中/严格两套口径 + 覆盖率）；**回访卡**（距上次检测满 3 天才出现）；继续检测；快速摸底 / 全量检测 / 开始新一轮；46 个分组的进度网格 |
| **总览** `pages/stats` | 已测/未测/覆盖率 + 四态统计；七段词频剖面（每条可点 → 直接复测该段缺口词）；检测记录（每轮日期、掌握率、词汇量） |
| **设置** `pages/settings` | 答题方式（自评 / 四选一）、严格口径、含派生词、**每日可投入时间**（15/30/60 + −/＋ 微调，5–180）、回访提醒开关、复制成绩单、清空作答记录、数据来源说明 |
| **答题** `pages/quiz` | 题面（词 / 音标 / 词频段）；自评三键或四选一；**作答后展开释义、短语、英中例句**；改判、撤销、跳过；精度实时提示；退出弹窗 |
| **报告** `pages/report` | 等级（S/A/B+/B/C/D → 卓越…基础薄弱，含高频段封顶）；七段剖面；补词优先级 Top3（缺口 × 词频权重）；基础段缺口；本轮明细；多轮对比；复测未掌握词 |

**移动端处理**：全部尺寸用 `rpx`；卡片圆角 + 单层阴影（不用毛玻璃，避免低端机掉帧）；
按钮最小 92rpx（≈44px）方便点；底部 Tab 用系统原生 tabBar；数字用等宽字体避免跳动。

## 四、数据怎么来的（要改数据就跑这两步）

```bash
node miniprogram/tools/gen-mini-data.mjs      # words.json + sentences.json → utils/*-data.js
node miniprogram/tools/gen-words-data.mjs     # 只要词库时用这个（老脚本，保留兼容）
```

- `utils/words-data.js`：7,175 词，字段与网页版 `build.js` 的裁剪完全一致
  （`w` 单词 / `t` 释义 / `b` 词库掩码 / `f` 频段 / `p` 音标 / `x` 派生词 / `ph` 短语）
- `utils/sentences-data.js`：5,138 个词各一句英中对照，语料来自 **Tatoeba（CC-BY 2.0 FR）**
- 打包体积 **约 1.52 MB / 上限 2 MB**（词库 824 KB + 例句 585 KB + 代码约 150 KB），不需要分包

## 五、测试怎么跑（不需要开发者工具）

```bash
node miniprogram/test/parity.mjs         # 引擎 vs 网页版：1302 条字段级断言 / 0 差异
node miniprogram/test/quiz-parity.mjs    # 答题流程 vs 网页版：34310 条 / 0 差异
node miniprogram/test/pages-smoke.mjs    # 五张页面在 Node 里跑一遍：26 项全过
```

`pages-smoke` 用 mock 的 `wx` 运行时把页面 JS 跑起来，能抓出拼写错误、引擎方法名写错、
`setData` 字段对不上、导航路径写错这类问题，**但测不到 WXML/WXSS 的渲染与手感**——
真机/模拟器里还是要自己点一遍（尤其答题页的三键高度和例句区换行）。

## 六、已知限制

- **发音**：需要 TTS 插件或后端，这一版没做（`onSpeak` 留了钩子）
- **AI 诊断**：网页版的 AI 面板不在小程序里。若要做，得在管理后台把大模型域名加进 request 合法域名，
  或走云函数转发——属于二期
- **词汇地图**：26 列网格在 375pt 宽的手机上每格不到 14rpx，做出来看不清，暂时用"七段剖面点开复测"代替
- **数据只在手机上**：换手机/清理小程序会丢；设置页可「复制成绩单到剪贴板」带走
- 移植细节（每一步改了什么、为什么）见 `IMPORT-NOTES.md`（很长，只在需要追溯时看）
