## 一、5 分钟跑起来（需要你做的）

1. **注册小程序拿 AppID**：<https://mp.weixin.qq.com> → 立即注册 → 小程序 → 个人主体（免费，注册完立刻有 AppID）
2. **装微信开发者工具**（稳定版）：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
3. 工具里「导入项目」→ 目录选 **`C:\Users\27295\cet4-vocab-check\miniprogram`** → AppID 填你自己的
   （或先在 `project.config.json` 里把 `"appid": "touristappid"` 换成你的 AppID）
4. 点「编译」。首屏出现「词汇账户余额查询」+ 余额卡就算成功
5. 点「快速摸底」→ 连续答题 → 测到精度达标会自动收工并进报告页

> 体验版/预览二维码：工具右上角「预览」扫码即可，**不需要备案、不需要发布**。
> 但要把评委加进「体验成员」才能扫（管理后台 → 成员管理 → 体验成员，有人数上限，提前收集微信号）。

## 二、现在有什么

| 页面 | 内容 |
| --- | --- |
| **首页** `pages/index` | 余额卡（词汇量 + 95% 区间 + 折中/严格两套口径 + 覆盖率）；快速摸底（±250 词，约 210 题）/ 全量检测（4540 词）/ 开始第 N+1 轮；46 个分组网格带每组进度；会话存在时显示「继续 →」 |
| **答题页** `pages/quiz` | 题面（词 / 音标 / 词频段）；自评三键（不认识 / 模糊 / 认识）；四选一模式（点右上角切换）；改判、撤销、跳过、下一个；精度实时提示；退出弹窗（看报告 / 保存返回 / 放弃 / 继续） |
| **报告页** `pages/report` | 等级（S/A/B+/B/C/D → 卓越/优秀/良好/中等/偏弱/基础薄弱，含高频段封顶约束）；频段剖面 7 段；提升优先级 Top3（缺口 × 词频权重）；地基缺口；本轮明细；多轮对比（保持率 / 新学进来 / 背了又忘 / 两轮都模糊）；复测未掌握词；开始新一轮 |

**和网页版一致的硬核部分**（算法一行没改）：词频分层抽样、FNV-1a 确定性定序、Agresti-Coull 区间、有限总体修正、蒙对校正、目标精度自适应停测、两套口径、7 频段剖面、等级 + 地基封顶、多轮 2bit 位图对比。

**这一版没有的**（二期或不做）：例句检索（`sentences.json` 1.19MB 未进包）、发音、AI 诊断面板、自定义词书导入、桌宠动效、键盘快捷键（触屏无意义）、词汇地图。


前两个是**一致性测试**：喂同一套作答，逐字段（连存档 JSON 都逐字节）比对网页版结果。第三个是**页面冒烟**：
真的把三个 Page 实例化、点按钮、连答 244 题跑到收工、再渲染报告页。

```bash

node miniprogram/tools/gen-words-data.mjs
```
