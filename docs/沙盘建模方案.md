# 词汇沙盘 · 建模方案

> 目标：把"七个词频段"做成一张**战略地图**——地形底图 + 等距城池 + 名牌 + 道路，
> 不是数据图表。所有内容程序化生成，不引入任何外部图片（单文件、离线可用是硬约束）。

## 一、图面结构（从下往上五层）

```
⑤ 名牌 / 标签    深色圆角牌：段位号 + 频段名 + 掌握率
④ 城池          等距投影：平台 → 城墙 → 角楼 → 主殿 → 旗
③ 道路          城池之间的土黄路径（贝塞尔 + 白色描边）
② 水系          两条河，带浅色岸线
① 地形          草色渐变 + 色斑 + 山脊 + 阴影
```

## 二、地形怎么画（无贴图，纯 canvas）

| 元素 | 画法 | 为什么这么做 |
|---|---|---|
| 底色 | 竖向渐变（深绿→浅绿） | 游戏地图都是"上深下浅"，有空气透视 |
| 草地肌理 | 400+ 个随机径向色斑，透明度 3%–8% | 纯平涂会像 PPT；色斑让它有"地图感" |
| 山脊 | 左右两半三角形（亮面/暗面）+ 山顶高光 | 两个三角形就能骗过眼睛 |
| 河流 | 贝塞尔曲线，10px 深色 + 4px 浅色高光 | 双层描边 = 水面的反光 |
| 阴影 | 城池下方压一个椭圆 + 偏移 | 有了投影才"站"在地面上 |

**关键：随机数用固定种子**（`20261114`）。否则每次重绘（悬停会触发）地形都会抖一下。

## 三、城池怎么建模

等距投影（2:1 菱形），一个「盒子」画三个面：

```
        ╱▔▔╲        顶面（亮）
      ╱      ╲
     │ 左面  │ 右面   两个侧面（一深一浅）
     └──────┘
```

一座城 = 5 个盒子叠出来：

| 部件 | 数量 | 尺寸 | 含义 |
|---|---|---|---|
| 平台 | 1 | 大菱形 | 这是"这一段的领地" |
| 角楼 | 4 | 小方盒 + 屋顶 | 城墙四角 |
| 主殿 | 1 | 中盒 + 屋顶 | 城的核心 |
| 旗 | 1 | 杆 + 三角 | 颜色 = 强弱 |

**视觉编码**（这是它作为"数据图"的部分）：

| 视觉量 | 映射 | 说明 |
|---|---|---|
| 平台直径 | 词量 (√ 缩放) | 991 词的段比 387 词的大一圈，但不会被压扁 |
| 主殿高度 | 掌握率 | 14 + 96 × p |
| 屋顶/旗颜色 | 掌握率 | 红 → 琥珀 → 绿 |
| 虚线轮廓 | 未测 | 空城：没有人、没有旗 |

## 四、名牌（照抄参考图的做法）

参考图里每座城下面是一块**深色圆角牌**，左边一个小方块写着等级/编号，右边是城名。

```
┌────┬──────────────┐
│ 01 │ 最高频 1k     │
│    │ 705 词 · 92%  │
└────┴──────────────┘
```

底色 `rgba(20,22,26,.82)`，白字，圆角 6px。等级号用频段序号 01–07。

## 五、交互

| 动作 | 结果 |
|---|---|
| 悬停城池 | 加一圈金色描边（像参考图里那个定位针）＋ 底部读数条更新 |
| 点击 | 直接复测这一段（`A.reviewCell(band,'all')`） |
| Shift + 点击 | 带着这一段的数字问 AI |
| 窗口缩放 | 重算尺寸重绘 |

## 六、性能

地形 + 河流 + 道路是静态的，画一次缓存到离屏 canvas（`MAPC.terrain`）。
悬停时只做「贴底图 + 画 7 座城 + 画名牌」，≈ 2ms，不会掉帧。
